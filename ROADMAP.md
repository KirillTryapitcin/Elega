# Roadmap

Milestones from the brief (Step 3) as approved in the Step 1 plan, in delivery order.
Basic moderation (M11a) moves right after chat so a closed alpha can start earlier.
Status lives in [docs/progress.md](docs/progress.md).

| Milestone | Scope                                                                                                                                                   |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M0        | Foundations: monorepo, tooling, Docker, CI, config, logging, health checks, design tokens, base UI kit, i18n skeleton, error handling, OpenAPI pipeline |
| M1        | Auth and accounts: registration, verification, login (email, VK ID, Yandex ID), sessions, password reset, settings shell                                |
| M2        | Profiles and media: uploads pipeline, avatar and cover, profile pages, privacy per field                                                                |
| M3        | Relationships: friends, follows, blocks, mutes, lists, basic suggestions                                                                                |
| M4        | Posts: composer, audiences, reactions, comments, bookmarks, sharing, polls, link previews, hashtags, mentions                                           |
| M5        | Feed: fan-out, chronological and ranked feed, pagination, new-posts pill, feed feedback                                                                 |
| M6        | Notifications and realtime: gateway, in-app, Web Push, email, preferences                                                                               |
| M7        | Chat: conversations, messages, receipts, presence, attachments, message requests                                                                        |
| M11a      | Basic moderation: reports, queue, actions, audit log (closed alpha starts after this)                                                                   |
| M8        | Search: indexing, typeahead, filters, privacy-safe queries                                                                                              |
| M9        | Groups, pages, events                                                                                                                                   |
| M10       | Stories                                                                                                                                                 |
| M11       | Moderation and admin, complete: appeals, metrics, automated filters                                                                                     |
| M12       | Hardening: performance, security review, accessibility pass, load tests, PWA polish, release candidate                                                  |
